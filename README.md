# Python_Games

# 🎮 Rock, Paper, Scissors Game

A Python implementation of the classic **Rock, Paper, Scissors** game built as part of the **Generative AI and Data Science Pathway (Module 1: Introduction to Python Programming for Data Science)**.

This project demonstrates core Python fundamentals, including control flow, user input handling, list operations, conditional logic, and pseudo-random number generation using the built-in `random` module.

---

## 📌 Features

- **Interactive Command-Line Interface:** Prompts the user to make a choice.
- **Case-Insensitive Input:** Automatically normalizes user inputs (e.g., `Rock`, `PAPER`, `scissors`).
- **Input Validation:** Gracefully handles invalid inputs and provides helpful error messages.
- **Randomized Computer Opponent:** Leverages Python's `random.choice()` function for un-biased AI moves.
- **Outcome Logic:** Clearly displays the user's move, computer's move, and determines whether the game ends in a Win, Loss, or Tie.

---

## 📐 Game Rules

1. **Rock** beats **Scissors**
2. **Paper** beats **Rock**
3. **Scissors** beats **Paper**
4. Selecting the same option results in a **Tie**
